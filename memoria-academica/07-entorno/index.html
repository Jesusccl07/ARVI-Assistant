7. Preparación del entorno

1 min de lectura

#7.1 Reconocimiento inicial

Antes de instalar nada se inspeccionó el equipo con comandos de solo lectura. El informe completo está en Análisis del entorno. Resumen:

Elemento Resultado
Sistema Windows 11 Pro 10.0.26200, 64 bits
CPU / RAM Intel Core i9-12900HK (14 núcleos, 20 hilos) / 23,7 GB
GPU Intel Iris Xe (sin CUDA)
Ya disponible Docker 29.8.0, VS Code, Obsidian 1.15.0, n8n en Docker, winget
No disponible Python real, Node.js, Git, GitHub CLI, Rust, Tailscale

#7.2 Instalaciones realizadas

Todas se hicieron con winget, tras la autorización expresa del usuario:

Herramienta Versión instalada Uso en ARVI
Python 3.12.10 Backend
uv 0.13.7 Entornos y dependencias reproducibles
Git / GitHub CLI 2.56.0 / 2.103.3 Control de versiones
Node.js LTS 24.20.0 Frontend
Rust (rustup) rustc 1.99.1 Aplicación de escritorio Tauri
VoiceStudio 0.5.8 (instalador verificado por SHA-256) Motor de voz local
Chromium de Playwright — Capturas y pruebas de interfaz

#7.3 Reutilización de la infraestructura existente

  • Obsidian: solo se leyó obsidian.json para localizar las bóvedas. La bóveda personal no se abrió ni se modificó. Se creó una bóveda nueva y separada: Documents\ARVI-Memory.
  • n8n: el contenedor n8n-local estaba detenido. Se arrancó con docker start (autorizado), sin recrearlo ni cambiar su configuración. Se inspeccionó sin revelar los valores de sus variables.

#7.4 Revisión del instalador de VoiceStudio

El instalador oficial se ejecuta con irm https://voicestudio.sh/install.ps1 | iex, que descarga y ejecuta código remoto. Por seguridad no se ejecutó así: se descargó el script, se leyó entero (148 líneas) y se comprobó que solo descarga el instalador de la release oficial de GitHub, verifica su SHA-256 contra SHA256SUMS.txt y lanza el asistente de instalación. Después se ejecutó la copia revisada.

#7.5 Incidencias del entorno

Ver INC-001 (rustup y --scope user) e INC-002 (alias de Python de la Microsoft Store) en el capítulo 19.
