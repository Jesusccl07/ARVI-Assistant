3. Análisis de requisitos

2 min de lectura

#3.1 Actores

Actor Descripción
Usuario Propietario del PC. Único usuario humano autorizado
Modelo de lenguaje (OpenAI) Sistema externo que interpreta las peticiones y propone llamadas a herramientas
Servicios externos n8n, Obsidian (archivos), VoiceStudio, Google, GitHub

#3.2 Requisitos funcionales

ID Requisito Prioridad Estado al cierre
RF-01 Conversar por texto con respuestas en streaming Alta Cumplido (P-007, P-039)
RF-02 Mantener el historial y resumir conversaciones largas Alta Implementado (MOCK)
RF-03 Crear, consultar, actualizar y archivar recuerdos Alta Cumplido (P-005, P-008, P-011)
RF-04 Buscar recuerdos y mostrar la nota de origen Alta Cumplido (P-007)
RF-05 Reindexar los cambios hechos desde Obsidian Alta Cumplido (P-001)
RF-06 Rechazar secretos en la memoria Alta Cumplido (P-001)
RF-07 Ejecutar herramientas locales permitidas Alta Cumplido (P-009)
RF-08 Pedir confirmación antes de acciones sensibles Alta Cumplido (P-010, P-011, P-038)
RF-09 Registrar en auditoría cada decisión sobre herramientas Alta Cumplido (P-001)
RF-10 Hablar por micrófono y recibir respuesta hablada Alta Cumplido con micrófono simulado (P-019). Falta repetirlo con el micrófono real
RF-11 Lanzar automatizaciones de n8n Media Cumplido (P-026)
RF-12 Consultar Google Calendar y Gmail (solo lectura) Media Implementado (MOCK, P-031); la prueba REAL espera la credencial
RF-13 Usar ARVI desde el móvil Media Parcial: PWA lista (P-029); falta activar tailscale serve
RF-14 Copia de seguridad y restauración de la memoria Media Cumplido (P-001)
RF-15 Atender llamadas telefónicas Baja No abordado (investigado, 16.8)

#3.3 Requisitos no funcionales

ID Requisito Cómo se verifica Resultado
RNF-01 Seguridad: ninguna acción sensible sin confirmación Pruebas de permisos Cumplido (P-027, P-038)
RNF-02 Privacidad: secretos fuera de Git y de la bóveda Filtro de secretos y revisión previa al commit Cumplido (P-027)
RNF-03 Mantenibilidad: proveedores intercambiables tras interfaces Pruebas con proveedor falso Cumplido: el motor de voz de respaldo se cambió sin tocar el agente (P-043)
RNF-04 Portabilidad de los datos: memoria en formato abierto (Markdown) Notas abiertas en Obsidian Cumplido
RNF-05 Rendimiento: primera palabra de respuesta en menos de 2 s (texto) scripts/e2e/latencia.py Cumplido: mediana de 0,64 s (P-039)
RNF-06 Accesibilidad: teclado, contraste y movimiento reducido axe-core (WCAG 2.2 AA) y recorrido con teclado Cumplido: 0 infracciones (P-040)
RNF-07 Coste: sin coste recurrente por la voz Motor local VoiceStudio Cumplido: el respaldo de pago está desactivado

#3.4 Historias de usuario

  • HU-01. Como usuario, quiero decir "Arvi, recuerda que mi proyecto final se llama ARVI" para que lo recuerde en futuras sesiones.
  • HU-02. Como usuario, quiero preguntar "¿cómo se llama mi proyecto final?" y que ARVI me diga de qué nota ha sacado la respuesta.
  • HU-03. Como usuario, quiero decir "abre Visual Studio Code" y que se abra si está permitido.
  • HU-04. Como usuario, quiero que ARVI me pida confirmación antes de archivar o borrar algo.
  • HU-05. Como usuario, quiero hablar con ARVI desde el móvil cuando estoy fuera de casa.
