23.4 Anexo E — Manuales

E.1 Manual de instalación

Requisitos (versiones con las que se probó, 2026-11-12):

Pieza Versión Para qué
Windows 11 Sistema anfitrión (DPAPI, aplicación de escritorio)
Python + uv 3.12 / uv reciente Backend
Node.js + npm 24 Interfaz
Obsidian cualquiera Opcional: ver y editar la memoria
VoiceStudio 0.5.8 Voz local (127.0.0.1:3900)
n8n 2.39 Opcional: automatizaciones (127.0.0.1:5678)
Rust + Build Tools de Visual Studio 1.99 / 2022 Solo para compilar la aplicación de escritorio

Pasos (PowerShell, en la carpeta del proyecto):

uv sync --all-groups --frozen                     # dependencias de Python (exactas, de uv.lock)
Copy-Item .env.example .env                       # y rellenar .env (ver la tabla siguiente)
cd frontend; npm ci; npx vite build; cd ..        # interfaz compilada en frontend/dist
uv run --no-sync arvi-server                      # http://127.0.0.1:8765

Variables mínimas de .env. Los valores reales nunca se suben al repositorio:

Variable Valor
OPENAI_API_KEY Clave de la API de OpenAI
ARVI_VAULT_PATH Carpeta de la bóveda fuera del repositorio, p. ej. C:\Users\<usuario>\Documents\ARVI-Memory. El backend no arranca si está dentro
VOICESTUDIO_PROFILE_ID Perfil de voz de VoiceStudio (vacío = voz por defecto)
N8N_API_KEY Opcional; después, uv run --no-sync python scripts/n8n/provision.py --aplicar
GITHUB_TOKEN, GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET Opcionales (capítulo 16)

La primera vez, el backend crea data/api_token con el token de acceso de la interfaz.

Comprobación: uv run --no-sync pytest -q debe terminar sin fallos. Esta secuencia se probó en una copia limpia del repositorio (P-042).

Aplicación de escritorio (opcional): cd frontend; npm run desktop:build genera src-tauri/target/release/bundle/nsis/ARVI_0.1.0_x64-setup.exe. Compila durante varios minutos y ocupa toda la CPU: conviene lanzarlo con prioridad baja si en el equipo corren otros servicios (INC-019).

Móvil (opcional): activar HTTPS en la consola de Tailscale y ejecutar tailscale serve --bg 8765. Nunca tailscale funnel, que publicaría ARVI en Internet.

E.2 Manual de usuario

  1. Abrir http://127.0.0.1:8765 (o la aplicación de escritorio) y pegar el token de acceso.
  2. Hablar: pulsar Hablar (o Tab hasta el botón y Enter), decir la frase y callar; la grabación se corta sola tras 1,4 s de silencio. Escribir: campo Mensaje y Enter.
  3. Interrumpir: Esc o pulsar la esfera.
  4. Colores de la esfera:
  5. azul cian: en espera;
  6. verde turquesa: escuchando;
  7. violeta: pensando;
  8. ámbar: ejecutando una herramienta;
  9. azul intenso: hablando;
  10. verde: hecho;
  11. rojo: error;
  12. gris: voz desactivada.

El estado también se muestra en texto bajo la esfera. 5. Aprobar acciones: las de nivel 2 (archivar un recuerdo, crear un issue o un evento) aparecen en la pestaña Permisos con una vista previa. Nada se hace hasta pulsar Aprobar. 6. Memoria: «Arvi, recuerda que…» guarda una nota en la bóveda. La pestaña Memoria busca entre los recuerdos, y en Obsidian se pueden leer y editar. 7. Respuesta hablada: la casilla del mismo nombre activa o desactiva la voz. ARVI habla siempre con la voz configurada en VoiceStudio. Si VoiceStudio no está abierto, responde solo en texto. 8. Integraciones: Estado → Integraciones muestra GitHub y permite conectar o desconectar Google.

23.5 Anexo F — Glosario

Término Definición
ADR Architecture Decision Record: registro breve de una decisión técnica, con su contexto y sus consecuencias
API REST Interfaz HTTP en la que cada recurso tiene una URL y se manipula con GET, POST, DELETE…
axe-core Motor de código abierto que comprueba automáticamente reglas de accesibilidad WCAG en una página
Bóveda (Obsidian) Carpeta de notas Markdown que Obsidian abre como una base de conocimiento. ARVI usa una propia, ARVI-Memory
CI Integración continua: ejecución automática de pruebas y auditorías en cada cambio del repositorio
CSP Content Security Policy: cabecera que limita de dónde puede cargar recursos una página
DPAPI API de Windows que cifra datos con una clave ligada al usuario y al equipo
Embedding Vector numérico que representa el significado de un texto, usado en búsquedas semánticas
FTS5 Extensión de SQLite para búsqueda de texto completo
Inyección de instrucciones (prompt injection) Ataque en el que un texto que el modelo lee como dato intenta darle órdenes
Loopback Dirección 127.0.0.1: solo accesible desde el propio equipo
LLM Large Language Model: modelo de lenguaje de gran tamaño (aquí, gpt-6-luna de OpenAI)
MOCK Prueba con un doble que sustituye a un servicio real (p. ej., un LLM falso)
n8n Plataforma de automatización por flujos (workflows), instalada en local en un contenedor
OAuth 2.0 Protocolo para que una aplicación obtenga permisos limitados sobre una cuenta sin conocer la contraseña
OmniVoice Modelo de síntesis de voz que usa VoiceStudio; permite diseñar o clonar voces
OWASP Fundación que publica guías de seguridad, como el Top 10 web y el Top 10 para aplicaciones LLM
PKCE Extensión de OAuth que impide usar un código de autorización interceptado
PWA Progressive Web App: web que se instala como aplicación y funciona sin conexión gracias a un service worker
Realtime API API de OpenAI por WebSocket para audio y texto en tiempo real; ARVI la usa como voz de respaldo
REAL Prueba ejecutada contra el servicio real, con evidencias
Refresh token Credencial de larga duración que permite pedir nuevos tokens de acceso sin volver a iniciar sesión
RTF Real-Time Factor: tiempo de síntesis dividido por la duración del audio; menos de 1 es más rápido que el tiempo real
Service worker Script que el navegador ejecuta aparte de la página y que puede responder peticiones sin red
STT / TTS Speech-to-Text (reconocimiento de voz) / Text-to-Speech (síntesis de voz)
Streaming Envío de la respuesta en fragmentos a medida que se genera
Tailscale Red privada virtual (tailnet) entre los dispositivos del usuario; serve publica un servicio solo dentro de ella
Tauri Framework para crear aplicaciones de escritorio con una interfaz web y un núcleo en Rust
Token de grano fino Token de GitHub limitado a repositorios y permisos concretos
VoiceStudio Aplicación local de voz (síntesis y reconocimiento) con una API compatible con la de OpenAI
WCAG Web Content Accessibility Guidelines: pautas de accesibilidad del W3C (niveles A, AA y AAA)
WebSocket Canal bidireccional y persistente entre navegador y servidor
Webhook URL que, al recibir una petición, lanza un flujo; aquí, los workflows de n8n
